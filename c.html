UNIT 1

Programming Languages

1.1 Definition

A programming language is the set of instructions through which humans interact with computers. These languages are used to give instructions and commands to the computer. Example: C, C++, Java.

1.2 History / Generation

  • First Generation Language (1GL) – Machine language (0 and 1)
  • Second Generation Language (2GL) – Assembly language
  • Third Generation Language (3GL) – C, C++, Java
  • Fourth Generation Language (4GL) – SQL, MATLAB

1.3 Classification

  • Machine level language
  • Assembly level language
  • Structured / Procedure oriented language
  • Object oriented language

Machine Level Language

Machine language uses only 0 and 1. It is very fast but very hard to write and understand.

Advantages:
  • Very fast
  • No translator needed
  • Efficient memory use
Disadvantages:
  • Very difficult to write
  • Hardware dependent
  • Difficult to debug
